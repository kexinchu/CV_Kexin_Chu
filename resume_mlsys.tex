\begin{rSection}{Research Publications \normalfont\small(\textbf{*} = representative work)}
\textbf{LLM Memory Systems.}
\begin{itemize}
    \item \textit{MCaM} (ICDCS 2025)\textbf{*}: Targets repeated-prefix prefill overhead in shared LLM serving by coordinating KV-cache reuse across HBM, DRAM, and SSD tiers. It cuts prefill latency by 69\% and raises throughput by 3.3x.
    \item \textit{SafeKV} (arXiv 2025)\textbf{*}: Targets privacy-safe shared KV-cache reuse in multi-tenant serving by isolating sensitive blocks while preserving reuse for non-sensitive prefixes. It preserves privacy while improving throughput by 2.66x over strict isolation.
    \item \textit{ReLACE} (under review)\textbf{*}: Targets recall drift in dynamic multimodal retrieval under OOD queries and online updates to multimodal data. It maintains 93.7\%--97.8\% recall across changing workload conditions.
    \item \textit{SQLens} (ongoing): Targets filtered vector search inefficiency when SQL predicates are applied after ANN traversal in PostgreSQL-based multimodal RAG backends. It delivers 1.4x--4.2x speedups across different selectivity settings.
\end{itemize}

\textbf{LLM Inference Optimization.}
\begin{itemize}
    \item \textit{ExpertFlow} (arXiv 2025): Targets host--GPU expert swap stalls in memory-constrained MoE inference through adaptive prefetching and cache-aware expert routing. It reduces model stall time to less than 0.1\% of baseline.
    \item \textit{DynaExq} (arXiv 2025): Targets precision misallocation under strict GPU memory budgets in MoE serving by dynamically promoting hot experts instead of using a fixed bit-width map. It delivers up to 2.73x higher throughput over ExpertFlow.
    \item \textit{MarginGate} (arXiv 2026): Targets batch-induced token flips in BF16 decoding without always-on verification. It restores 100\% deterministic decoding with 15.05\%--18.56\% trigger rates and cuts LLM-42 latency overhead by up to 2.23x.
    \item \textit{LQM-ContextRoute} (arXiv 2026): Targets same-function tool-provider routing under runtime load and quality heterogeneity in LLM agents. It improves search F1 by 2.18 points and StrategyQA accuracy by up to 18 points over SW-UCB.
\end{itemize}
\end{rSection}
